# 年末漫遊｜2027 台灣跨年演唱會指南

Responsive static website for mobile and desktop. Open `index.html` locally to preview.

## Included

- Taiwan-wide concert guide with North, Central, South, and East filters
- Favorites saved in the browser's local storage
- A small character guide with region navigation and simple chat interactions
- Cross-region transportation and late-night travel reminders
- A membership sign-in / sign-up interface prototype

## Deploy to Vercel

1. Create a GitHub repository and upload this folder (the site is a static `index.html`).
2. In Vercel, import the repository.
3. Keep the framework preset as **Other** and leave the build command and output directory empty; deploy.

## Notes

Concerts shown are planning examples because official 2026/12/31 event details are not yet announced. Confirm event, transit, and traffic-control details with official organizers and transport agencies. The member form is a front-end prototype and needs an authentication provider and backend before it can create persistent accounts.
